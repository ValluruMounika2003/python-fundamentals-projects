# Python Beginner Projects

A collection of beginner-friendly Python projects created while learning Python programming and problem-solving skills.

## Projects Included

* BMI Calculator
* Tip Calculator
* Roller Coaster Ticket System
* Treasure Island Adventure Game
* Banker Roulette
* Rock Paper Scissors Game

## Skills Practiced

* Variables and Data Types
* User Input and Output
* Conditional Statements
* Nested If-Else Logic
* Lists
* Random Module
* Basic Problem Solving

## Goal

These projects were built to strengthen Python fundamentals and develop logical thinking through hands-on coding practice.
